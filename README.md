# Coffee Sales Analysis Dashboard

## 📌 Project Overview

This project presents an in-depth **Coffee Sales Analysis** using **Power BI**. The goal is to transform raw sales data into actionable insights that drive strategic business decisions.

From a **Business Intelligence (BI)** perspective, this project demonstrates the application of **data modeling, ETL processes, KPI tracking, and interactive reporting** to support stakeholders in monitoring performance and identifying growth opportunities.

---

## 🎯 Business Objectives

1. Track overall sales performance across different time periods.
2. Identify top-performing coffee products, categories, and regions.
3. Monitor revenue trends, profit margins, and average order values.
4. Provide decision-makers with dynamic, interactive dashboards for quick insights.

---

## 🛠️ BI Concepts & Technologies Applied

* **Data Extraction & Transformation (ETL):** Using Power Query to clean and prepare raw sales data.
* **Data Modeling:** Establishing relationships between sales, customers, and products.
* **DAX (Data Analysis Expressions):** Creating calculated measures such as Total Revenue, Profit, and Sales Growth %.
* **Dashboarding & Visualization:** Using Power BI visuals to highlight KPIs and trends.
* **Drill-Down & Filtering:** Enabling stakeholders to explore data by product, region, and time.

---

## 📊 Dashboard Features

* **Sales Overview:** Total revenue, sales quantity, and profit margins.
* **Trend Analysis:** Sales performance across daily, monthly, and yearly timeframes.
* **Product Insights:** Best-selling coffee types and underperforming products.
* **Regional Analysis:** Sales distribution by geography or store location.
* **Customer Behavior:** Average order value, repeat purchases (if data available).

## 📈 Key Insights (Sample)

* Seasonal peaks in coffee sales indicate strong demand during **winter months**.
* Certain premium coffee products generate higher profit margins despite lower sales volume.
* Regional variations suggest opportunities for **targeted marketing campaigns**.

## 🚀 How to Use

1. Download the `coffee sales.pbix` file.
2. Open it in **Power BI Desktop**.
3. Interact with the dashboard by applying filters and drilling down into categories.
